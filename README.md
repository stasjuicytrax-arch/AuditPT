# AuditPT · Party Time

Демонстрационная панель аудита продаж Party Time. Показывает причины закрытия заявок, путь до брони, динамику и примеры разбора разговоров. По умолчанию открыт трёхмесячный период с 23 августа по 22 ноября 2026 года. Доступны отдельные месяцы, две последние недели по отдельности и фильтр по локации.

В этой версии используются вымышленные заявки и тексты. Рабочая аналитика и данные Битрикс24 хранятся отдельно. Для внутреннего отчёта с живыми данными нужен закрытый сервис с входом для сотрудников.

## Запуск

Из папки проекта выполните `python -m http.server 8765 --bind 127.0.0.1` и откройте `http://127.0.0.1:8765/`. Сборка и установка пакетов не требуются.

## Оформление

За основу взяты фирменные макеты барного меню Party Time A5 и A4. Используются графитовый фон, белый логотип, лаймовые столбцы причин, голубая воронка, шрифты Unbounded и Onest. В качестве референсов для композиции использованы Class Tickets и Frameform из рабочей библиотеки. Статичное зерно взято из локального рецепта проекта «Караоке Рейв».
